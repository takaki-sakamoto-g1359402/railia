## Source precedence

1. These images define canonical character identity, silhouette, facial feel,
   palette, celestial motifs, ears, tails, cloak/robe language, and blue
   crystal accents.
2. `../design-breakdowns/` defines proposed separation and motion structure.
3. `../../production-workbench/` contains temporary reconstruction candidates
   only. A candidate must be corrected if it conflicts with canonical identity.

These are rendered references, not production PSD layers. Never treat their
backgrounds, lighting, hidden overlaps, or flattened pixels as proof of a
deformation-safe layer stack.
