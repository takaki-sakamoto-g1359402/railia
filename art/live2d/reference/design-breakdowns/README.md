# Riai / Noa Live2D design-breakdown references

These files are preserved as **DESIGN REFERENCES ONLY** for material separation,
layer naming, expression planning, and secondary-motion planning. They are not
production PSD layers and must never be cropped into an import PSD.

The labels, white backgrounds, arrows, guide marks, sample composites, and any
other sheet-layout content are explicitly excluded from production art. Every
Cubism part must be reconstructed as a clean transparent raster layer with
sufficient hidden overlap for its approved deformation range.

Canonical character identity still comes from the approved primary Riai and Noa
references. If a breakdown sheet conflicts with a primary reference, the primary
reference wins. These sheets may guide separation and motion only.
